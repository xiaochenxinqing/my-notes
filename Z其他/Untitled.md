# 一、加密关服务器



1）修改平台服务端nginx配置

执行命令

```
vi  /data/etc/nginx.conf
```

 

找到“server” 部分： 

```
    server {
        # 为了提供给SSL卸载服务使用
        listen 127.0.0.1:48443; 
        # 默认所有网口都没配置管理口时，时都支持访问管理口的
        listen 0.0.0.0:443 ssl;
        listen [::]:443 ssl;
         ............
```

 

将下方其中两行的443修改为目标端口

 

然后执行命令：

 

```
nginx -s reload
```

 

2）使proxy访问新端口

 将附件中的dss.conf 放置在/etc下，修改文件中的端口443为目标端口。



然后执行命令：

```
dssctl 
```

按提示输入10，按提示重启现有proxy（早期版本若不存在序号为10的选项，直接重启服务器可达到相同效果）





 

 

# 业务端

1）Driver模式接入的应用：

linux系统修改/etc目录下，windows系统修改C:\etc\下 的dss.conf 文件中的443端口为目标端口，然后重启业务服务。



2）Proxy模式接入的应用：

无需任何改动。
